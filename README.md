# XYROO — Neo-Brutalist Portfolio

Static portfolio siap deploy. Tidak membutuhkan VPS/backend.

## File
- `index.html` — struktur website
- `style.css` — Neo-Brutalist UI
- `script.js` — menu mobile, status animation, project tilt
- `assets/` — tempat gambar/logo jika diperlukan

## Ganti informasi
Cari dan ubah:
- `Xyroo`
- `hello@example.com`
- link GitHub / Telegram / Instagram
- daftar project
- stack teknologi

## Deploy gratis
Bisa dipasang di GitHub Pages, Cloudflare Pages, Netlify, atau Vercel.

Untuk domain `porto.nett.to`, arahkan DNS sesuai instruksi provider hosting yang dipilih.
